# 本地案例数据

`private/air-france-mirror.xls`：已下载的完整公开课程镜像，未经修改。

`private/inspected-data.json`：由原文件解析出的浏览器工作台数据，包含源行号、字段映射和检查结果。

`private/inspection-report.json`：汇总与检查报告。

这些文件只在当前电脑保留，不进入 Git 或网站部署包。重新复制项目时，可运行 `npm run data:download` 下载并校验完整公开镜像，再运行 `npm run data:inspect`；也可导入自行取得的 KEL321 正式文件。不要把缺失文件替换成随机数据或模拟经营记录。

本地服务只绑定 127.0.0.1，只有两个明确允许的文件地址可供网页读取；正式部署不包含该服务或这些文件。本地首页的“下载完整 Excel”无需先导入；“下载当前原文件”则保存当前导入字节。部署页提供公开仓库链接与浏览器内读取，均不上传数据。
