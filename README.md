# 广告投放经营分析实战课程

面向产品、运营及有一定数据分析能力的学员，目标为约 2 小时的系列上机课程。

## 交付目标

- 有可核验来源的完整案例数据。
- 一个课程引导网站。
- 围绕案例连续展开的 4 道大题。
- 从案例数据计算的题目可视化、分析过程与参考答案。
- 尽可能覆盖广告投放经营流程，并明确数据无法支持的环节。

## 已确认的内容要求

用户于 2026-09-14 明确要求：不编造数据，从业界知名广告数据分析课程中寻找合适的现有案例。

先核验课程、案例和官方配套数据，再确定题目与网站内容。不采用先编故事、再生成数据的方式。不得把不同企业案例拼接为同一次投放，也不得把教学情景推演当作真实观测值。

## 当前版本：Air France · 经营调查进阶版

已完成可运行的课程网站、4 道连续经营调查题、评分依据、讲评、数据导入和可视化工作台。时间为 10 分钟导入 + 20 / 25 / 30 / 25 分钟上机 + 10 分钟讲评，共 120 分钟。课程采用 Kellogg Air France 案例（正文 KEL319，数据 KEL321），有 NYU Stern 课程大纲采用证据。

已下载并检查公开学生课程仓库的完整 Excel 镜像，含 DoubleClick 4,510 条明细与独立 Kayak 汇总。**镜像尚未与官方发行版本核对，不等同于官方真实性认证或再分发授权。** 正式开课前请通过学校/发行方取得正式材料并复核。网站支持直接更换文件，所有结果重新计算。

## 运行

需要 Node.js 20 或更新版本，无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:4317/ 。数据页点击“载入本地课程镜像”，或自行选择 XLS / XLSX / CSV。仅本机服务会提供已下载文件；部署版本使用浏览器文件导入，不包含课程原始数据。

```sh
npm test
npm run check
node scripts/export-course.mjs
```

前两项验证计算、真实文件解析（文件存在时）、静态资源及发布内容边界；第三项从统一的课程定义导出题目。查看另一个原始文件可运行 `node scripts/inspect-data.mjs 文件路径`，该脚本只检查与输出本地数据，不修改原始文件；镜像来源标记仅适用于默认文件。

## 已实现内容

| 大题 | 工作台与交付 |
| --- | --- |
| 01 审计经营报表 | 独立 CPC/CPA/ROAS 复核、异常源行、加权口径审计 |
| 02 检验渠道排名 | 可编辑品牌词组规则、共同分层权重、原始与标准化对比、分类导出 |
| 03 定位低效投入 | CPA 对称分解、10/50/100/200 门槛比较、候选花费与前十项重合 |
| 04 为预算方案答辩 | 同预算三方案、新增分配部分效率折损、失效点、前题证据引用 |

每题先保存独立初判，再打开分析；填写结论和三项证据后进入讲评。第四题要求前三题针对同一数据已提交，并保存当前的三方案比较。修改前题证据会撤销后题提交状态，但保留原作答；更换数据按指纹区分提交。旧版草稿保留，需要按新版要求补充证据。

作答可导出 Markdown，包含初判、计算值、证据、分析范围、前题引用快照和压力测试。没有学生账户、服务器收卷或自动评价经营答案。
