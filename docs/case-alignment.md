# 四题与原案例的对应

课程单一来源为 dist/assets/course.mjs，执行 npm run course:export 同步问题与完整参考答案讲义。

| 本课 | 原材料主题 | 本课方法补充 |
|---|---|---|
| 指标体系 | 原题 1–2 的广告效果与回报 | 指标共创、公式平台、口径与缺口 |
| 因果验证 | 原题 1 的额外购买 | 数据质量、95% 区间、识别条件 |
| 经营决策 | 原题 2 的成本/回报/对照代价 | 增量核算、条件区间、盈亏阈值 |
| 下一轮实验 | 原题 3–4 的频次、时段与下轮投放 | 探索 vs 因果边界、事前随机策略、样本规划 |

案例开场与课堂安排在讲义中先于四题。原题主题与参数参考正文镜像，网站仅作摘要与教学改编，不复制完整题干或声称官方答案。旧 Air France 对应说明保留在 docs/reference-air-france/。
