# 实现与验证记录

- 原始文件通过固定 Git blob、SHA-256、字节数、六列结构、唯一用户与缺失检查；未修改原始记录。
- 采用 Node 纯函数重算完整文件，检查分组、频次、星期和小时切片守恒。
- 使用 Python 标准 CSV 阅读器独立聚合；statsmodels 0.15.0 的 Newcombe 区间结果与网站一致。
- 样本规划在 50%、20%、4% 对照比例下，与 statsmodels 双侧 5%、功效 80% 的近似公式一致。验证中的 MDE 0.5 个百分点是测试规划参数，不是案例观测或课程推荐阈值。
- `scripts/validate-rocket.py` 可复现独立验证；需可用的 statsmodels、scipy。网站和 Node 测试不依赖这些 Python 库。
- 31 项 Node 测试覆盖原 Air France、Rocket Fuel 原始文件、无数据呈现、安全公式、经济核算、样本规划与证据保留/失效逻辑。
- 浏览器检查：完整文件自动读取和手动导入；自定义跨组指标；本地保存；前题修改使后题提示重交但保留原文字；成本情景更新；时段探索；MDE/分流交互；原始 PSA 购买用户筛选 420 行及分页；小组导入新增副本。
- 手机首页在 390px 下无页面水平溢出。旧站可通过独立入口进入，并读取原 Air France 数据。
- 导出由浏览器发给同源本机服务，保存在 data/private/exports 独立目录，再提供下载链接；不上传至远端。该设计避免依赖内置浏览器对临时 Blob 下载的处理。

后续每次变更仍需按 AGENTS.md 运行适当检查、检查本地服务，修改服务端后重启。没有 Sites 发布动作。
