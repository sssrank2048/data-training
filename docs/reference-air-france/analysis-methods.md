## 当前四题的计算

- 题一：Total Cost、Clicks、Impressions、Total Volume of Bookings、Amount 先求和，再计算 CPC、CTR、CVR、CPA、ROAS 和每次预订收入。所有金额原精度计算、展示时四舍五入。零分母显示不可计算，异常保留。
- 题二：按原始 Publisher Name 分组重算指标；四象限横轴 CPC、纵轴预订/点击，参考线为全量加权值，气泡面积按花费。规模和效率共同决定建议，不推断扩量因果收益。
- 题三：按渠道+活动分组；匹配方式+出价策略在当前渠道范围内比较。关键词筛选只改变明细范围，不从全量数据删除记录。默认点击门槛为 0，由学员自定并注明；无广告文案时不构造内容或效果。
- 题四：对 Kayak 独立汇总计算相同比率，并单独标注观察期间；不加入主表分子分母。主表日期未知，图表为非同期描述性参照。缺少曝光时 CTR 不可计算，不用虚拟值。

## 故事图表与可复算解答

`courseEvidence` 统一生成故事和四题答案的证据：全部渠道的花费/收入份额分别以全量成本/收入为分母，份额图使用同一个 0–100% 尺度。最高花费渠道作为诊断优先项，最高历史 ROAS 渠道作为扩量验证候选；这些是描述性筛选，不是最优预算规则。

## 品牌词分层及共同结构比较

将关键词统一大小写、Unicode 重音、标点与空格。词组规则按完整词组边界匹配；默认规则为 `air france, airfrance`，可由学员修改。不做拼写自动修正。未命中称为“非品牌候选”，不能当成经过验证的非品牌标签；缺少关键词另列。

只保留两渠道均有正点击的品牌/非品牌候选层作为共同覆盖范围。共同权重为两渠道在该层合并点击数 / 两渠道所有共同层合并点击数。标准化 CVR、CPC、收入/点击分别用该权重求和；标准化 ROAS = 标准化收入/点击 ÷ 标准化花费/点击。

页面报告各渠道共同层点击 / 全部点击的覆盖率。无共同层、相同渠道或空规则不输出有效比较。该调整没有控制其他关键词意图、地域或用户差异，不是因果估计，也不是扩量回报。

## CPA 的对称分解

比较 A 与 B，令 C = CPC，V = 1/CVR，则 CPA = C × V。

- 点击成本贡献 = (C_A − C_B) × (V_A + V_B) / 2
- 预订率贡献 = (V_A − V_B) × (C_A + C_B) / 2

贡献之和严格等于 CPA_A − CPA_B，相当于对两种替换顺序取平均。正负号标识推高或降低差额，不能解释为因果贡献。任何一侧 CPC、CVR 无法计算或非正时不分解。

## 点击门槛敏感性

同一渠道、同一关键词查询范围内，筛选零预订且点击达到门槛的记录。比较 10、50、100、200 及学员当前门槛。汇总候选记录数、花费和占所选范围花费的比例，比较花费前十项与当前门槛前十项的重合数。参照候选不足十项时显示实际分母；排序以源行号打破同花费并列。

门槛是教学筛选规则，不是统计显著性标准。候选花费不是可无损节省的预算。原始记录不因筛选从数据中删除。

## 同预算三方案与压力测试

共同预算按美分分配；先取整，再按小数余数从大到小补足，避免四舍五入后总额不一致。

1. 历史占比分配：共同预算 × 历史渠道花费占比。
2. ROAS 权重分配：共同预算 × 渠道历史 ROAS / 渠道 ROAS 之和。这是机械比较基准，不是优化器。
3. 学员自拟方案：必须完整分配共同预算，才能保存比较。

历史效率收入 = Σ预算 / 历史 CPC × 历史 CVR × 历史每次预订收入。

压力情景先对所有预算施加学员指定的 CPC、CVR 相对变化，再仅对超过“同预算历史占比分配”的渠道预算部分，追加 CVR 折损。此“新增部分”相对的是同预算基准，不是已经观察到的新增流量，也不代表真实流量容量。

设未追加折损时自拟方案相对历史占比方案的收入优势为 E，新增分配部分的未折损收入为 X。若 E>0、X>0，则使优势消失的折损比例为 E/X。只有结果在 0%–100% 内才呈现为该模型的失效点。若本来就没有优势，或分母/效率不可计算，明确显示对应状态。

本模型不含真实扩量曲线、流量容量、时间趋势、机票履约成本或随机对照证据。压力值是显式假设；不提供预测区间、置信区间、利润预测或因果增量。
