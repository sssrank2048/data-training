# 案例事实与四题对照（2026-09-15 核对）

## 可核实的业务背景

[Kellogg 官方案例摘要](https://www.kellogg.northwestern.edu/academics-research/research/detail/2009/airfranceinternetmarketingoptimizinggoogleyahoomsnand/)描述：Media Contacts 的 Rob Griffin 为 Air France 优化 SEM；目标关乎广告投入与在线机票销售；决策涉及渠道投入、关键词、出价策略。摘要说明先定义 KPI、以渠道四象限比较点击成本与销售转化表现，并使用活动/策略透视表；同时纳入 Kayak 的讨论。

网站故事只概述这些内容，没有加入虚构人物、预算、会议情节、经营危机或结果。课堂分析者的角色是本课安排。
