# Rocket Fuel 计算方法

所有核心计算是 dist/assets/analytics.mjs 与 investigation.mjs 的纯函数，读取真实教学文件，不向静态资源写入派生明细。

1. 一行一 Cookie 用户。严格检查六列、0/1 组别及购买、整数曝光、星期和小时范围。空值不能当 0；重复/异常保留源行，阻止推断，不静默删行。
2. 对随机组别先求购买总数与用户数，再求转化率；差值 = 商业广告组 − PSA 组。差值单位为百分点，相对提升以 PSA 转化率作分母。
3. 两个 Wilson 比例区间通过 Newcombe 方法组合成独立两比例差的 95% 区间。基于独立二项用户与随机化/追踪前提；数据不能验证全部前提。
4. 增量用户 = 差值 × 商业组人数；基线购买 = PSA 转化率 × 商业组人数。它是期望分解，不识别具体个体的因果状态。
5. 增量贡献 = 增量用户 × 单位贡献。默认成本 = 全体商业广告与 PSA 曝光 × CPM / 1000。增量净贡献 = 增量贡献 − 成本；ROI = 增量净贡献 / 成本。不是完整企业净利润。
6. 经济性区间只传播比例差区间，固定输入 CPM 和单位贡献。不包含参数估计、外推或边际扩量风险。支持仅商业曝光的替代成本范围，但不混作整个试投。
7. 频次分箱、星期、小时图是描述性探索；星期/小时指曝光最多的时段，不是购买时点。各切片显示真实分子与分母，不作策略因果推断。
8. 样本规划：双侧 α=.05、功效 .8、独立二项样本的大样本近似；使用零假设合并方差、备择方差和实际分配比率。输出向上取整。不计聚类、流失或连续窥视。
9. 自定义公式只支持白名单 COUNT / SUM / MEAN、T / C 分组函数、四则运算与括号。无 eval。user_id 只能计数；拒绝不存在字段。百分比/百分点在展示层乘 100。
10. 小组证据绑定文件 SHA-256、课程版本、指标定义、当前及前题草稿、相关情景/计划。历史快照不可被后续编辑覆盖，导入新建副本。
